검색

SKU는 수입품번 + 컬러 + 사이즈 기준이며, 같은 수입품번에 품번 코드가 여러 개인 경우 판매·재고를 합산했습니다. RT 대상 SKU = 창고재고 0 이하(재고없음). 품번 정렬은 해당 품번 RT 대상 SKU의 2주판매 합계 내림차순이며, 같으면 품번 전체 2주판매 순입니다.
2주판매·창고재고는 DB 시트(1.판매, 2.창고재고) 기준이며, 26AW의 입고·판매(누적)·판매율은 26AW 시트 수불수량 기준입니다(판매율 = 판매 ÷ 입고). 카드를 누르면 품번의 전체 SKU 현황을 볼 수 있습니다. 의류(여성)은 의류에, 수입모자는 모자에 포함됩니다.
